# WSL2のインストール

最終更新: 2026-08 ／ 対象: Windows 11、Ubuntu（WSL2）

Windows上でLinuxを動かすために、WSL（Windows Subsystem for Linux）を準備します。Linuxディストリビューションには Ubuntu を用います。

---

## 1. WSL2とUbuntuのインストール

画面下のWindowsボタンを押し、検索窓に `PowerShell` と入力して、表示された項目を**管理者として実行**します。以下を入力してEnterを押します。

```
wsl --install -d Ubuntu
```

インストール可能なディストリビューションの一覧は以下で確認できます。バージョンを指定したい場合は、この一覧の名前を `-d` に渡します。

```
wsl --list --online
wsl --install -d Ubuntu-24.04    # バージョンを指定する例
```

再起動を求められたら再起動します。

Windowsボタンを押して検索窓に `Ubuntu` と入力し、インストールされた **Ubuntu** を起動します。

初回起動時にUsernameとPassword（Ubuntuにログインするためのもの）を聞かれるので入力します。**必ず半角英数字**にしてください。日本語は使えません。このパスワードは `sudo` を実行するたびに必要になります。

最初にパッケージを更新しておきます。`update` で更新の必要なパッケージを確認し、`upgrade` で実際に更新します。

```
sudo apt update
sudo apt upgrade -y
```

これでインストールは完了です。

> **補足**: 現在のWSLはGUIアプリの表示（WSLg）に標準対応しています。以前必要だったXサーバ（VcXsrv等）の導入は不要です。

---

## 2. Windowsターミナル

Windows 11ではWindowsターミナルが標準搭載されています。スタートメニューから「ターミナル」で起動できます。

複数のシェル（PowerShell、Ubuntu等）をタブで切り替えられるため、以降の作業はWindowsターミナルから行うのがおすすめです。

（Windows 10を使っている場合は、Microsoft Storeから「Windows Terminal」を入手してください。ただしWindows 10はサポートが終了しています。）

## 3. Ubuntuの初期設定

### WindowsからWSL上のファイルにアクセスする

Windowsのエクスプローラーのアドレス欄に以下を入力してEnterを押します。

```
\\wsl.localhost
```

Windowsの画面からWSL上のファイルを閲覧・編集できます。

（以前は `\\wsl$` という表記が案内されていました。現在も動作しますが、`\\wsl.localhost` が推奨表記です。）

### 作業ディレクトリの選び方

WSLからWindows側のファイル（`/mnt/c/...` 以下）を読み書きすると、**著しく遅くなります**。ファイルシステムをまたぐためです。

計算やビルドは必ずLinux側のホームディレクトリ（`/home/ユーザ名` 以下）で行ってください。MD計算のように大量のファイルを出力する場合、この違いで実行時間が何倍も変わることがあります。

Windows側のファイルは、必要なときだけコピーして使うのが基本です。

### シンボリックリンクを作る

Windowsでいうショートカットにあたります。例として、Ubuntuのホームディレクトリに、Windowsのデスクトップへのリンクを作ります。

```
cd
ln -s /mnt/c/Users/「Windowsのユーザ名」/Desktop
```

ファイルの受け渡しが楽になります。ただし前項のとおり、計算そのものはLinux側で行ってください。

### lsのエイリアスを作る

色分け・詳細表示・更新時間順（古い順）・隠しファイルも表示、という設定にします。

```
cd
vim .bashrc
```

最終行に以下を追記します。

```
alias ls="ls -ltra --color=auto"
```

各オプションの意味は以下のとおりです。

| オプション | 意味 |
|---|---|
| `-l` | 詳細表示（パーミッション、サイズ、更新日時） |
| `-t` | 更新時間順に並べる |
| `-r` | 並び順を逆にする（`-t` と併せて古い順、最新が下に来る） |
| `-a` | 隠しファイル（`.` で始まるファイル）も表示する |
| `--color=auto` | 種類ごとに色分けする |

### カレントディレクトリをエクスプローラーで開くエイリアスを作る

Ubuntu上で作業していて「このディレクトリをWindowsで開きたい」というときに使います。同じく `.bashrc` の最終行に追記します。

```
alias open=explorer.exe
```

保存したら反映させます。

```
source ~/.bashrc
```

以降、次のコマンドで現在のディレクトリをエクスプローラーで開けます。

```
open .
```

## 4. 基本操作

Linuxを初めて使う場合は、ここだけ押さえておけば作業を始められます。

- 現在のディレクトリを表示する

```
pwd
```

- ディレクトリの中身を確認する

```
ls
ls -l    # 詳細
ls -lt   # 詳細かつ更新時間順
ls -ltr  # 詳細かつ更新時間順（古い順）
```

- ホームディレクトリに移動する

```
cd       # または
cd ~/
```

- 絶対パスで移動する

```
cd /xxx/xxx/xxx
```

- 相対パスで移動する

```
cd ./      # 現在のディレクトリ
cd ./xxx   # 現在のディレクトリ直下のxxxへ
cd ../     # ひとつ上のディレクトリへ
```

- ファイルの中身を確認する

```
cat xxx    # 全体を一度に表示
less xxx   # 先頭から順に表示（Enterで進む、qで終了）
tail -F xxx  # 末尾を表示し続ける（計算ログの監視に使う）
```

- エディタ（vim）でファイルを編集する

```
vim xxx
```

| 操作 | キー |
|---|---|
| 編集モードに入る | `i` |
| 編集モードから戻る | `Esc` |
| 保存して終了する | `Esc` → `:wq` |
| 保存せずに終了する | `Esc` → `:q!` |

---

## 5. その他（Windows PowerShell上の操作）

- インストールされているディストリビューションとWSLのバージョンを確認する

```
wsl -l -v
```

- Ubuntuをシャットダウンする

```
wsl --shutdown
```

- Ubuntuを削除して初期化する（**中身はすべて消えます**）

```
wsl --unregister Ubuntu
```
